## 🚀 Featured Projects

### 💰 FinTrack

A scalable personal finance and budget-management backend built with **Java, Spring Boot, MySQL, JPA/Hibernate, audit logging, pagination, RBAC, and REST APIs**.

Key areas include:

* Budget management
* Accounts and transactions
* Categories and merchants
* Role and permission management
* Audit logging
* Scalable API architecture
* Database optimization
* High-load readiness

---

### 👥 Elevora HR

An HR and employee development platform designed to support:

* Employee management
* Departments and organizational structures
* Skills and proficiency tracking
* Training management
* Tutor/instructor workflows
* Employee assessments
* Notifications
* Role-based dashboards

Built using **Laravel, React, Inertia.js, Tailwind CSS, MySQL, queues, and email automation**.

---

### 💻 Ovey Store

An e-commerce and savings platform for electronics retail featuring:

* Product inventory management
* Order processing
* Target savings
* Payment verification
* Transaction management
* Administrative dashboards
* Search, filtering, sorting, and pagination

Built with **Laravel, React, Inertia.js, Tailwind CSS, MySQL, and Cloudinary**.

---

### 🏥 HealthCare Connect

Contributing as a volunteer developer to a **Digital Patient Intake System MVP** designed for rural healthcare environments.

The solution focuses on:

* Digital patient registration
* Medication information
* Patient record visibility
* Pre-populated patient data
* Reduced manual data entry
* Improved clinical workflow
